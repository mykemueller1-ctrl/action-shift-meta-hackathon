Restaurant front desk · Meta Muse prototype

From craving to kitchen.

The food starts a conversation. Action Shift carries the request through current facts, a clear quote, the operator’s decision and the kitchen handoff—even when the plan changes.

Built by Myke Mueller · Never86’d

Fictional restaurant records. Recorded Muse results. Simulated handoffs. This silent video includes on-screen captions. Model responses shown are saved results from real Meta API tests using synthetic inputs. Opening this page makes no model request. Kitchen, table and remedy receipts are local simulations; no customer message, real order, booking, payment or refund is created.

The operator makes the commitment

A request keeps its history.

An expired special stays expired. Conflicting quantities stay open until clarified. Approval belongs to one exact version, and a change requires another decision.

The front desk also includes ordinary direct orders, table requests and service recovery. The source records what has been demonstrated and what remains to connect.

  3. 03 Preserve the handoff when something changes.

Run it locally.

This page hosts the video. The interactive prototype runs on your computer with Node.js 22 or newer. Recorded replay needs no API key or dependency installation.

git clone https://github.com/mykemueller1-ctrl/action-shift-meta-hackathon.git
cd action-shift-meta-hackathon
node src/front-desk-demo.mjs

Then open http://127.0.0.1:4330/front-desk. Stop the local server with Ctrl+C. The simulation’s session state resets when it restarts.
